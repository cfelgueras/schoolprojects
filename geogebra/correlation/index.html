Correlation

Project 2, “Is It True?”: how to enter a table of values in GeoGebra Classic, draw a scatter graph, and find the regression line, r and the mean point.

Chapters

The commands

  • Scatter graph: select the table → right-click → Create → List of points
  • Scale: ZoomIn(xMin, yMin, xMax, yMax)
  • Regression line: FitLine(l1)
  • r: r = CorrelationCoefficient(l1)
  • Mean point: Z = (Mean(x(l1)), Mean(y(l1)))
  • Estimate: f(3)

If something goes wrong

  • You cannot see the points? They are outside the graph: use ZoomIn with ranges that include your data.
  • l1 is a lowercase L and the number 1.
  • Do not call the mean point M: the points of your table are already called A to T.
  • Your table shows 5.50 instead of 5.5? That is the rounding to 3 significant figures; the value is the same.
  • A wrong number in the table changes everything: check it before you draw the graph.
