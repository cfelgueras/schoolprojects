# Exponents and logarithms — summary

**Laws of exponents 🧠:** $a^m a^n = a^{m+n}$ · $\dfrac{a^m}{a^n} = a^{m-n}$ · $(a^m)^n = a^{mn}$ · $a^{-n} = \dfrac{1}{a^n}$ · $a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$

| Need | Formula 📘 |
|---|---|
| Definition | $a^x = b \Leftrightarrow x = \log_a b$ |
| Product / quotient / power | $\log_a xy = \log_a x + \log_a y$ · $\log_a \dfrac{x}{y} = \log_a x - \log_a y$ · $\log_a x^m = m\log_a x$ |
| Change of base | $\log_a x = \dfrac{\log_b x}{\log_b a}$ |
| Inverses | $a^x = e^{x \ln a}$ · $\log_a a^x = x = a^{\log_a x}$ |

**Graphs:** $y = a^x$ → HA $y = 0$, through $(0,\ 1)$ · $y = \log_a x$ → VA $x = 0$, through $(1,\ 0)$ · reflections of each other in $y = x$.

**Equations:** same base → equate exponents · otherwise take logs · log equations → combine, rewrite as a power, **check** every solution.

**Hidden quadratics:** $e^{2x}$ and $e^x$ → let $u = e^x$; reject $u \leq 0$.

**Watch out:** $\log(x + y) \neq \log x + \log y$ · on the GDC, $\log$ is base $10$.
