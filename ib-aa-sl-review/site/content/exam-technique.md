# Exam technique

:::note The two papers (SL)
| | Paper 1 | Paper 2 |
|---|---|---|
| Calculator | **Not allowed** | **Required** (GDC) |
| Time | 1 h 30 min | 1 h 30 min |
| Marks | 80 | 80 |
| Structure | Section A: short questions in the answer boxes. Section B: long questions in the answer booklet. | Same structure |
| Formula booklet | Clean copy provided | Clean copy provided |

That is roughly **1 minute per mark**. A 6-mark question deserves about 6–7 minutes — move on if you are stuck and come back later.
:::

## 1. Command terms — what the question is asking

The verb at the start of a question tells you **how much working** you need.

| Command term | What to do | Working needed? |
|---|---|---|
| **Write down** | Give the answer directly; it should be obvious or quick. | Little or none |
| **State** | Give a name, value or short answer. | None |
| **Calculate** | Get a numerical answer, showing the important steps. | Yes |
| **Find** | Get an answer, showing the important steps. | Yes |
| **Solve** | Find the values that make the equation (or inequality) true. | Yes |
| **Show that** | Prove the given result. The answer is already given, so the marks are **only** for the working. | Every step |
| **Hence** | Use the result you have just found. Other methods get no marks. | Yes, using the previous part |
| **Hence or otherwise** | Using the previous part is the quickest route, but any correct method is accepted. | Yes |
| **Sketch** | Draw the general shape with the key features labelled (intercepts, turning points, asymptotes). Not to scale. | Labels |
| **Draw** | An accurate, labelled diagram or graph, to scale, with a ruler for straight lines. | Accuracy |
| **Estimate** | Get an approximate value. | Some |
| **Describe** | Give a detailed account (e.g. "translation by 3 units to the right"). | Words |
| **Justify** / **Explain** | Give a valid reason (e.g. "because $f''(x) < 0$ for $x < 2$"). | A reason |
| **Determine** | Get the only possible answer. | Yes |
| **Deduce** | Reach a conclusion from the information given. | Yes |
| **Differentiate** / **Integrate** | Find the derivative / integral. | Yes |
| **Interpret** | Explain what a result means in context. | Words |
| **Verify** | Show that a given value satisfies the conditions. | Substitution |

## 2. What to write when you use the GDC (Paper 2)

Examiners only see your paper, not your calculator screen. For every GDC result:

1. **Write the equation, function or command in maths notation** — e.g. "$-4.9t^2 + 14t + 1.5 = 0$", "$\displaystyle\int_0^6 \lvert v\rvert \,\mathrm{d}t$", "$X \sim \text{B}(12,\ 0.365)$".
2. If you used a **graph**, sketch it and mark the point you used.
3. Write the **answer** with the right accuracy and units.

:::mistake Calculator notation is not accepted
Do **not** write key presses or calculator syntax such as `nDeriv(`, `solve(`, `normalcdf(` or `d/dx(X^3,2)` as your working or final answer. Write it the way a mathematician would.
:::

## 3. Accuracy: three significant figures

- Unless the question says otherwise, give answers **exactly or correct to 3 significant figures (s.f.)**: $\pi \approx 3.14$, $0.0123456 \approx 0.0123$, $12\,345 \approx 12\,300$.
- **Do not round in the middle of a calculation.** Keep the full value in the GDC (use `Ans` or store it) and round only the final answer. Rounding early can make the final answer wrong and lose the mark.
- If the question asks for **2 decimal places** (money) or **the nearest integer**, follow that instead.
- **Exact** answers ($\sqrt{2}$, $\dfrac{5}{3}$, $\ln 4$, $\dfrac{\pi}{6}$) are expected on Paper 1, and whenever the question says "exact" or "in the form…".
- Simplify final answers: $\sqrt{\dfrac{25}{4}}$ should be written $\dfrac{5}{2}$, and $\dfrac{10}{5}$ should be $2$. A fraction does not need to be in lowest terms, as long as top and bottom are integers.

## 4. Radians or degrees?

| Use **radians** when… | Use **degrees** when… |
|---|---|
| The question uses $\pi$ or "radians" | The question uses $^\circ$ |
| Arc length $l = r\theta$ and sector area $\dfrac{1}{2}r^2\theta$ | Triangles given in degrees (sine rule, cosine rule, bearings) |
| Trig **functions** of $x$ (graphs, equations like $\sin 2x = \dfrac{1}{3}$ for $0 \leq x \leq \pi$) | Angles of elevation / depression |
| Calculus with trig functions | |

:::tip Check the mode before every Paper 2 trig question
A wrong angle mode can cost every mark in the question, and the markscheme often says "do not accept an answer in degrees".
:::

## 5. How to read a markscheme

Markschemes tell you **where each mark comes from**. Learn to mark your own work with them.

| Symbol | Meaning |
|---|---|
| **M** | **Method** mark: for attempting a correct method (e.g. substituting into the right formula). |
| **A** | **Answer / accuracy** mark: for a correct value or expression. Usually needs the M mark before it. |
| **R** | **Reasoning** mark: for a clear explanation or justification. |
| **AG** | **Answer given** — the result was in the question, so it earns no marks itself; the marks are for the working before it. |
| **FT** | **Follow through**: if you made a mistake earlier, you can still earn marks for using your wrong value correctly later. |
| **( )** brackets | **Implied** marks, e.g. ***(M1)***: you get them if your later working or answer shows you must have done that step, even if it is not written. |
| **M1A1** on one line | M1 for the method, A1 for doing it with the correct values. |
| **A2**, **M2** | Worth 2 marks that are not split. |

**Other things you will see:**
- **METHOD 1 / METHOD 2** — different complete methods; any one gets full marks.
- **EITHER … OR … THEN** — alternative ways to do one step; then the common ending.
- **"their"** (e.g. "using their $m_{\text{BC}}$") — follow through from your own earlier answer.
- **Note** boxes — what is accepted and what is not (e.g. "do not accept $L = 3x + 26$").
- **$\ldots$ after a number** (e.g. $7.48331\ldots$) — the full unrounded value.

:::example How to self-mark with a markscheme
**Steps**

+++

1. Compare your working with the markscheme **line by line**, not just the final answer.
2. Give yourself each **M** mark if you used a correct method, even if the numbers went wrong.
3. Give **A** marks only for correct values (or correct follow-through from your earlier answer).
4. Bracketed marks count if your answer is correct even when the step is not written.
5. Note **why** you lost each mark: method? algebra slip? accuracy? wrong angle mode? That tells you what to practise.
:::

## 6. Checklist for exam day

- [ ] Calculator charged, in the right mode, memory reset if your school requires it.
- [ ] Read every question to the end before starting it; underline the command term.
- [ ] Show working for anything that is not "write down".
- [ ] Give units, and 3 s.f. unless told otherwise.
- [ ] Use the formula booklet — but know where each formula is.
- [ ] Leave time to check: units, signs, angle mode, that you answered every part.
