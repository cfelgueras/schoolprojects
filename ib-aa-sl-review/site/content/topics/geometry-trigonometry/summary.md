# Geometry and trigonometry — summary

| Need | Formula |
|---|---|
| SOH CAH TOA 🧠 | $\sin = \dfrac{\text{opp}}{\text{hyp}}$, $\cos = \dfrac{\text{adj}}{\text{hyp}}$, $\tan = \dfrac{\text{opp}}{\text{adj}}$ |
| Sine rule 📘 | $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$ — ambiguous case: $B$ or $180^\circ - B$ |
| Cosine rule 📘 | $c^2 = a^2 + b^2 - 2ab\cos C$ |
| Area 📘 | $\dfrac{1}{2}ab\sin C$ |
| Arc / sector 📘 | $l = r\theta$, $\ A = \dfrac{1}{2}r^2\theta$ (radians) |
| 3D distance 📘 | $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2}$ |
| Volumes 📘 | pyramid $\dfrac{1}{3}Ah$ · cone $\dfrac{1}{3}\pi r^2 h$ · sphere $\dfrac{4}{3}\pi r^3$ |
| Surfaces 📘 | cone $\pi r l$ · sphere $4\pi r^2$ |
| Identities 📘 | $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$ · $\cos^2\theta + \sin^2\theta = 1$ |

**Exact values 🧠:** $\sin \dfrac{\pi}{6} = \dfrac{1}{2}$, $\sin \dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$, $\sin \dfrac{\pi}{3} = \dfrac{\sqrt{3}}{2}$ (cos in reverse order) · $\tan \dfrac{\pi}{4} = 1$.

**Trig graphs 🧠:** $y = a\sin(b(x - c)) + d$ → amplitude $\lvert a\rvert$, period $\dfrac{2\pi}{b}$, axis $y = d$.

**Equations:** isolate → first solution → all solutions in the interval (CAST / symmetry; extend the interval for $2x$).

**Watch out:** angle mode (Deg / Rad) · obtuse angles have negative $\cos$ and $\tan$.
